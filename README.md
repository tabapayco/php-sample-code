# TabaPay PHP

A PHP library for integrating with the TabaPay payment gateway, providing seamless transaction creation and automatic verification.

## Features
- Easy integration with TabaPay API  
- Secure and reliable payment processing  
- Automatic transaction verification  
- Callback support for real-time status updates  

## Files
- `TabaPay.php` – Core library for handling API requests  
- `Verify.php` – Script for verifying transactions  
- `Sample.php` – Example implementation  

## Requirements
- PHP 7.2 or later  
- cURL enabled on the server  

:warning: This is just sample code do not use in your production service.

Stable branch does not included " Auto Verify " functions, see auto-verify branch instead.
